# hermes-skills

A [Hermes Agent](https://github.com/NousResearch/hermes-agent) skills tap.

Add it:

```bash
hermes skills tap add KoenradusXLVIII/hermes-skills
```

Or install a single skill without subscribing to the whole tap:

```bash
hermes skills install KoenradusXLVIII/hermes-skills/radicale-calendar
```

## Skills

| Skill | Description |
|---|---|
| [`radicale-calendar`](skills/radicale-calendar/SKILL.md) | Check, create, reschedule, and delete calendar appointments via Radicale (self-hosted CalDAV). |
| [`ikea-dirigera`](skills/ikea-dirigera/SKILL.md) | Control IKEA smart lights and scenes via a DIRIGERA hub. |
